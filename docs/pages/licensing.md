# Licenses

Py-Feat's original software is **MIT-licensed**, including commercial use.
Pretrained models and research datasets have separate terms. Choose the
notice for the product and model family you use:

| Product | Original software | Models and data |
|---|---|---|
| [Py-Feat v1.0 / Detectorv1](licensing_v1.md) | MIT | Separate notices for each component and fitted artifact. |
| [Py-Feat v2.0 / Detectorv2](licensing_v2.md) | MIT | Multitask checkpoint, pretrained backbone, teachers, and training data have separate terms. |
| [PyFeat-Live](licensing_live.md) | MIT | The selected detector and optional model assets keep their own terms. |

“V1.0” and “v2.0” here identify the classic and multitask model families,
not Python package version numbers. See the
[dataset register](licensing_datasets.md) for training, model-selection,
and evaluation roles and the evidence supporting each entry.

For a future model intended for commercial users, see the
[commercial retraining table](licensing_commercial.md). It distinguishes
commercial training, public weight sharing, and unresolved permissions.

The software license does not establish unrestricted commercial use or
redistribution of every pretrained asset. Some assets have explicit
noncommercial terms; others have unresolved upstream grants or
dataset-agreement scope. An unresolved permission is not filled by adding
an MIT or research-only label. Existing valid grants are not revoked by
these notices.

The [repository MIT License](https://github.com/cosanlab/py-feat/blob/main/LICENSE)
and third-party notices should be preserved in distributions. Signed data
agreements and private correspondence are retained outside the public
repository. This page was reviewed October 8, 2026.
